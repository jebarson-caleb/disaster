# Complex Query Notes

The file `database/04_complex_queries.sql` includes examples for:

- High-priority pending rescue ranking with disaster joins.
- Emergency load compared with visible hospital capacity.
- Resource distribution totals per disaster and category.
- Shelter matching for rescue groups requiring relocation.
- AI assessment audit history for active disasters.

The file `database/02_views_procedures_triggers.sql` includes:

- Views for active emergencies, hospital availability, shelter availability, and pending high-priority rescues.
- Procedure `assign_rescue_unit` for rescue assignment.
- Procedure `plan_resource_distribution` for relief supply allocation.
- Triggers for rescue history, hospital capacity logs, and shelter capacity logs.
