## Defect Remediation Summary

1. **DEF-01 (High) — SQLite ResourceWarning with `-W error`:**
   - **Root Cause:** Under Python 3.13, stricter garbage collection tracked unclosed connection handles in SQLAlchemy's test engine pool during `conftest.py` teardown.
   - **Fix:** Explicitly invoked `db.engine.dispose()` during `app` fixture teardown in `backend/tests/conftest.py`. Rerun backend suite under strict `-W error` with 78 passed tests.

2. **DEF-02 (High) — Zod Memory Exhaustion Advisory (GHSA-mrhx-c7xc-m3w5):**
   - **Root Cause:** Transitive dependency `zod@4.4.3` via `eslint-plugin-react-hooks` and `zod-validation-error` had an uncapped recursion flaw.
   - **Fix:** Upgraded `zod` to patched version `4.6.7` and updated `frontend/package-lock.json`. `npm audit` now reports 0 vulnerabilities.

3. **DEF-03 (Medium) — Session Restoration Delay on App Launch:**
   - **Root Cause:** Initial `restoreSession()` request without a client-side timeout blocked the sign-in screen indefinitely during cold starts, with potential race conditions overwriting manual user authentication.
   - **Fix:** Added a 3.5s timeout (`DEFAULT_SESSION_RESTORE_TIMEOUT_MS`) with `AbortController` in `frontend/src/services/api.js`. Added `sessionCheckActiveRef` in `frontend/src/App.jsx` to guard against late responses and immediately unblock the operational login screen.
