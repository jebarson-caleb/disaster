# Security Policy

## Supported versions

Security fixes are applied to the latest commit on `main`. Earlier commits and demo deployments are not supported.

## Reporting a vulnerability

Do not open a public issue or include real incident, victim, credential, health, or location data in a report. Contact the repository owner privately through the GitHub profile associated with this repository and include:

- the affected endpoint or component;
- a minimal reproduction using synthetic data;
- the security impact;
- any suggested mitigation.

The operator should acknowledge a report within three business days, keep the reporter informed during triage, and coordinate disclosure only after a fix or mitigation is available.

For the platform's implemented controls, data-handling requirements, and beta limitations, see [Security and privacy](docs/SECURITY_PRIVACY.md).
